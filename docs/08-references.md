# Referencias técnicas oficiales — consulta inicial 2026-09-28; comprobación selectiva 2026-09-29

Estas referencias se deben revisar de nuevo antes de congelar versiones o contratar planes.

- [Astro — Content Collections](https://docs.astro.build/en/guides/content-collections/): esquemas, colecciones y tipos.
- [Astro — Testing](https://docs.astro.build/en/guides/testing/): Vitest y Playwright.
- [AstroWind — repositorio y licencia](https://github.com/arthelokyo/astrowind): plantilla, componentes y licencia MIT para el código.
- [Calendly — precios](https://calendly.com/pricing): limitaciones por plan.
- [Calendly — embed avanzado](https://calendly.com/help/advanced-calendly-embed-for-developers): widgets, mensajes y parámetros.
- [Calendly — API vs embed](https://calendly.com/help/calendly-embed-and-the-api): restricciones importantes de la API pública.
- [SimplyBook.me — precios](https://simplybook.me/pricing): proveedores, reservas y features.
- [Fresha — precios](https://www.fresha.com/pricing): suscripciones y comisiones del marketplace.
- [Google Search Central — LocalBusiness](https://developers.google.com/search/docs/appearance/structured-data/local-business): datos estructurados válidos.

No integrar una plataforma de pagos hasta verificar disponibilidad y condiciones para Argentina y el comercio concreto.

- [Astro — Deployment](https://docs.astro.build/en/guides/deploy/): salidas estáticas y adaptadores cuando se requieran.
- [GitHub — Mermaid](https://github.blog/developer-skills/github/include-diagrams-markdown-files-mermaid/): diagramas versionados en Markdown.
- [Google — SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide): contenido útil y estructura rastreable.
