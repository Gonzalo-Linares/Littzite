# PR-17/18 — estado del candidato VIORA

Rutas legales, metadata social, sitemap/robots, JSON-LD condicionado y guard explícito están implementados en PR-17. El pulido PR-18 mantiene el sitio noindex mientras `VIORA_PUBLIC_RELEASE` no sea `true`; no hay dominio, deploy ni Search Console configurados. La ubicación footer-only del acceso de arrepentimiento requiere revisión jurídica explícita antes de release. La fecha de este estado no implica aprobación legal ni comercial. Ver [docs/19](19-viora-release-readiness.md) para blockers y pruebas.
